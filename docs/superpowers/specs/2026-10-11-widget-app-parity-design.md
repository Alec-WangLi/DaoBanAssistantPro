# 桌面小组件贴齐 App（设计）

- 日期：2026-10-11
- 起因：用户 v0.11.3 真机测完后的一条 —— 原话「我想让你实现的这个小组件效果，跟咱们APP里面的基本一致。不管用什么方法，能够实现个八九成像也可以。现在感觉有点太粗糙了。」
- 前一句是更具体的点名：「尤其是今日的强调色没有用上咱们的玻璃滑块。」
- 影响版本：v0.11.9 测试版
- 与用户的约定（2026-10-11）：
  - **「八九成像」就是验收线** —— 不追求逐像素等于 App。桌面是另一套渲染管线，够不着的部分要说明白，不要假装够得着。
  - **深色模式必须一并考虑**（用户原话：「同时你还要注意深色模式下的」）。
  - **月历恢复「每格一张白卡」**（用户 2026-10-11 在两个真机方案里选了 A）。

## 1. 现状：两边摆在一起

三张卡分别放在桌面最后两页（**月历单独最后一页，周条 + 今日卡在倒数第二页**）。2026-10-11 用真机截图（`screencap`）逐处对照过 App 与桌面：

| 在哪 | App | 桌面小组件（改之前） |
|---|---|---|
| 月份网格 | 每格**一张独立白卡**（白 92% + 6% 黑描边 + 小圆角 + `black 5% blur 6` 的投影），格子之间有缝 | 42 格**直接摊在一整块板上**，靠间距与明度分区 |
| 「今天」（App 里其实是**选中**那一天） | 两层叠出来的：一枚**半透明**的主色选择块（标准档 = 14% 淡染 + 2px 主色描边；液态档 = 一枚玻璃透镜）**加上**格内容自己翻成「实心」样式（`_shiftChip(solid: true)` → 底色铺满 + `onSolid` 字，见 `calendar_screen.dart:1916`）。合起来才读作「一块蓝块 + 白字」 | 日数字只是**染成主色**的一串字 |
| 「今天」徽章（今日卡） | **实心主色药丸 + 白字** | 14% 淡染 + 45% 描边 + 主色字（与普通班次胶囊同一配方） |
| 卡片底 | 白卡垫在 `#F5F6FA` 的页面上；卡有**渐变 + 一圈边光 + 投影** | 渐变两端只差 **1%**（白 97% → 96%），等于没有；**没有投影** |
| 日期那行（今日卡） | 「10月11日 **星期日**」 | 「10月11日」—— **缺星期几**（粗细本来就对：布局里写着 `textStyle="bold"`） |

**渐变被压平是有原因的、不是随手写的**：那两端的不透明度是 2026-09-18 为了让文字在**任意壁纸**上都过 AA 才提到 94~97% 的（`widget_colors.xml` 顶部那段注释记了整段推导：深色卡白 16% 叠浅色壁纸时字直接糊掉）。代价就是玻璃感归零。**这一轮不许为了「更像」把这个数偷偷调回去** —— 要动它，先重算那一组对比度。

**⚠️ 一处有意为之的偏离：桌面这版把「今天」铺成真·实心块，App 那边不是。** App 那枚选择块是**半透明**的 —— 它画在网格**之上**，做成不透明就会把格子里的日期 / 胶囊 / 农历全糊掉（`calendar_screen.dart:2195` 那段注释记着这条推导，还写着「别把 boxShadow 加回来」，同一个道理）。今天之所以读起来像「实心蓝块」，是**液态档那枚透镜压得够实 + 格内容自己翻成实心样式**两件事叠出来的。桌面这版直接铺实心，理由两条：

1. 桌面**没有实时模糊**，半透明的主色块压在**任意壁纸**上会直接消失 —— 那正是用户报的「太粗糙 / 今日的强调色没用上玻璃滑块」；
2. 用户 2026-10-11 是在**看过这个效果的真机图**（A / B 两版 × 浅深两档）之后选的 A。

**所以这是有意的偏离，不是抄错了。** 构建者把它跟 App 并排比时，看到「桌面的今天更实」是对的，**不要去「修正」成半透明**。

## 2. 目标 / 非目标 / 反目标

**目标**

- 月历卡：恢复「每格一张白卡」，并让「今天」成为一块实心主色块。
- 今日卡：把「今天」徽章从淡染改成实心主色 + 白字。
- 周条：今天那一列同样铺实心主色块（它和月历卡摆在同屏，不能一个有一个没有）。
- 三张卡在**浅色与深色两档**下都成立。

**非目标**

- 不做真实的背景模糊（做不到，见 §3）。
- 不动 Dart 侧的快照协议（`widget_snapshot.dart` 的字段够用：`weekday`、`lunarShort`、`accent`、`themeMode` 都已在快照里）。
- 不改三张卡的尺寸与内容组织（`resizeMode="none"`、编译期定死）。
- 不做动画 / 逐分钟刷新（刷新粒度仍是跨天 + 班次边界）。

**反目标**（技术上做成了也算失败）

- 为了像而牺牲可读性：格子卡底的不透明度掉到壁纸能透出来的程度。
- 42 格各烤一张唯一位图 → 把 `WidgetChip` 的 LruCache（64 条）冲爆。
- 「今天」那块块的颜色不再是主色（比如写死成蓝色）。
- 浅色下好看、深色下糊成一片（或反过来）。

## 3. 桌面这个媒介的硬约束

这一节是「八九成像」里「剩下那一两成」的来源，**每一条都有代价**：

1. **没有实时背景模糊。** `RemoteViews` 是**宿主进程**渲染的，采不到壁纸，也挂不了 `BackdropFilter`。玻璃感只能靠**描边 / 圆角 / 渐变**去近似。所以桌面上永远不会像 App 那样有真实折射。
2. **不能 `setTypeface(int)`。** `TextView` 没有那个重载，反射调用会在宿主进程抛 `ActionException` —— 字重只能**写死在布局**里（`android:textStyle`）。
3. **位图一律被 `fitXY` 拉伸。** 圆形/圆角位图的宽高比与控件对不上时，圆角会被拉成椭圆。所以：**能用静态 `<shape>` 的就不要烤位图**；非烤不可的（颜色是用户选的），位图尺寸要**贴近控件的真实像素尺寸**。
4. **`WidgetChip` 的缓存是按 (颜色, 形状, 尺寸) 键的 LruCache，上限 64 条。** 逐格造唯一尺寸/颜色会把它冲爆 —— 所以 42 格的胶囊尺寸恒定。
5. **宿主 `reapply` 只重放新的动作串。** 同一个容器每渲染一次就多一层子视图（v0.9.9 的「重影」），所以 `addView` 前必须 `removeAllViews`；而且**每个视图的状态两个方向都要设满**（该 GONE 的要显式 GONE）。
6. **`MainActivity` 的 requestCode 池已经排满**（班次闹钟 0..600 / 自定义 10000..11000 / 待办 20000..21000 / 重复系列 40000..41999 / 自检 99998·99999 / 小组件 100000 起）。本轮**不加任何新的点击目标**，所以不动那个池。
7. **Kotlin 里不许出现用户可见的中文字面量**（文案全在 Dart 侧的 `L10n`，随快照过来）。

## 4. 决定：A 版

2026-10-11 出了两版真机对照图（A「每格白卡」/ B「整块平铺」，各含浅色与深色），**用户选 A**。

**A 版成立的前提是一件容易看漏的事**：App 里格子之所以读得出「一张卡」，是因为它垫在 **`#F5F6FA` 的页面**上。桌面上没有「页面」这一层，所以要让白卡显出来，必须**让月历卡的面板去扮那个页面**：

- **月历卡的面板底 = App 的页面色**（浅色 `#F5F6FA` 系、深色 `#0B0B10` 系，各带一个很轻的渐变），`radius 22dp` 不变；
- **每一格 = 一张白卡**（浅色：白填充 + 6% 黑描边；深色：`#1B1B22` + 白 10% 描边），`radius 12dp`，格子之间留缝。

**周条与今日卡不跟着变**（它们扮的是 App 的「信息卡」，本来就是白的）。

**「今天」的处理三处统一**（这是用户点名的那一处）：

| 在哪 | 做成什么 |
|---|---|
| 月历那一格 | 整格铺**实心主色块**（圆角与格子卡底同为 12dp），日数字 / 农历走 `onSolidInk`，格内胶囊转**实心班次色 + `onSolidInk` 字**（与 App 的 `_shiftChip(solid: true)` 同一件事：底色铺满 + on-solid 字） |
| 周条那一列 | 与月历格**逐条对齐**：整列铺实心块（`match_parent`，与外层那 2dp 缝一致），周几 / 日数字 / **胶囊同样转实心 + `onSolidInk`**。两张卡在同一屏上，这里要是「块铺了、胶囊还是淡染」，同一件事就会有两种长相 |
| 今日卡的「今天」徽章 | 从淡染改成**实心主色 + `onSolidInk` 字**（药丸仍是 52×24dp，圆角取高度的一半） |

**块上文字一律走 `onSolidInk`** —— 一个运行期函数，**按块的颜色现算**（相对亮度 > 0.55 取近黑，否则取白），不是「浅色档一套、深色档一套」两个固定值。与 App 的 `AppTokens.onSolid` 是同一件事：主色是用户可选的，白字压在 teal / orange 上过不了 AA（`AGENTS.md` 那条量过：teal 2.63 / orange 2.55），黑字也未必行，按亮度二选一恒有 ≥ 4.58:1。

⚠️ **它管的不只是「今天」那块**：格内的班次胶囊一旦转实心，字也压在**任意班次色**上（用户还能自定义任何颜色），所以**每一个实心胶囊都要过这个函数**。§5 里那两个 `wg_on_solid_*` 是它的**两个候选值**，不是输出。

## 5. 怎么实现（spike 里已经跑通的那一套）

2026-10-11 已经**用真机走过一遍**（两版各出一个构建、浅深各截一次图），下面这些是**已验证可行**的，构建者照做即可：

**新增位图原语**（`WidgetChip.kt`）：

```kotlin
fun block(color: Int, w: Int, h: Int, radiusPx: Float,
          borderColor: Int = 0, borderPx: Float = 0f): Bitmap
```
—— 圆角实心块（可选描边）。三处都用它：月历那一格的今天、周条那一列、今日卡的「今天」药丸。

**格子卡底用静态 `<shape>`，不烤位图**（`res/drawable/widget_cell_light.xml` / `_dark.xml`）：圆角随控件尺寸走，天然不会被 `fitXY` 拉成椭圆。运行期按深浅档 `setInt(root, "setBackgroundResource", …)`。

**「今天」那一格多一层**：`widget_month_cell.xml` 的根从 `LinearLayout` 改成 `FrameLayout`，多一个 `ImageView wg_mc_block`（`match_parent` + `fitXY`，压在内容下面；非今天显式 `GONE`）。周条的 `widget_strip_cell.xml` 同样加 `wg_sc_block`。

**⚠️ 今天那一格不许「白卡上面盖块」。** 块是烤好的位图、卡底是静态 drawable，两者宽高比对不上时会在四个角上**露出白卡的角尖**。做法：今天那一格把卡底**置 0**（`setBackgroundResource(0)`），让块自己充当那张卡。**两个方向都要设满** —— `reapply` 只重放新动作，漏了「置空」这一支，翻月之后白卡会留在一格不落。

**位图尺寸从 `AppWidgetOptions` 现算**（`monthCellPx` / `stripCellPx`）：格子的尺寸是 `GridLayout` 的 `rowWeight` 在布局期算出来的，渲染这侧拿不到，所以按实际 dp 反推。**行数必须按当月真实可见行数算**：5 行月每行约 77dp、6 行月约 65dp（差 18%），拿固定 6 行去反推会让 5 行月那格明显偏矮。可见行数 = `ceil((前导空格数 + 本月天数) / 7)`，而前导/尾随空格渲染这侧本来就在算。反推得粗一点没关系（它只影响圆角），**但别粗到宽高比失真** —— 那正是上面那条「露角尖」的成因。

**颜色**（`res/values/widget_colors.xml` 新增）：

| 令牌 | 值 | 用在哪 |
|---|---|---|
| `wg_cell_fill_light` / `wg_cell_border_light` | `#FFFFFFFF` / `#0F000000`（黑 6%） | 浅色档的格子卡底 |
| `wg_cell_fill_dark` / `wg_cell_border_dark` | `#FF1B1B22` / `#1AFFFFFF`（白 10%） | 深色档的格子卡底 |
| `wg_on_solid_light` / `wg_on_solid_dark` | `#FFFFFFFF` / `#FF111818` | `onSolidInk` 的**两个候选**（近黑而非纯黑，与 `wg_ink_*` 同一族） |
| `widget_page_light.xml` / `_dark.xml` | **不透明** `#FFF5F6FA`→`#FFF1F3F8` / `#FF0B0B10`→`#FF15151B` | 月历卡的面板底（扮 App 的「页面」） |

**⚠️ 面板必须不透明，这条是算出来的、不是口味**：月历卡的标题行与周几行用的是 `wg_muted_light`，改版把它们从「白 96% 的卡」挪到了「`#F5F6FA` 的面板」上。随手写 97% 的话：

- 叠**黑壁纸**（最坏那一头）= `0.97 × 245 ≈ 238` → 与 `#6E6E82` 只有 **4.33:1 —— 跌破 AA 4.5**；
- 改成**不透明** → **4.61:1 ✓**（原来那条白卡 96% 是 4.57，所以这一改是把它救了回来，不是放宽）。
- 深色档两侧都够（不透明面板上 `wg_muted_dark` ≈ **7.1:1**）。

这条与 §1 末尾那条「别把 94~97% 偷偷调回去」是**同一条纪律的另一半**：改一个面的颜色之前，先把落在它上面的那几个字的对比度算一遍。

## 6. 验收

**这一轮的验收只能靠真机**：桌面小组件走原生 `RemoteViews`，Dart 视觉工装（`app/tool/visual/`）**画不出来** —— 这是仓库既有的、写过好几次的一条（v0.9.0 的更新说明配图里，小组件那一张只能用真机桌面截图）。

- **真机出图**：三张卡 × 浅色 / 深色两档，与 App 的对应界面**并排**看一遍。⚠️ **矩阵不止这两维** —— 至少还要各加一档：
  - **主色调要挑最坏的那两颗**（`teal` / `orange`）：本轮第一次让**主色去当背景**（今天那块块），而这两颗正是「白字压上去过不了 AA」（2.63 / 2.55）的那两颗，`onSolidInk` 该在这一档里把它们判成黑字。只用默认的蓝去看，这条永远照不出来；
  - **语言切到英文**：「今天」药丸的宽度是**写死的 52dp**（RemoteViews 量不到文字宽度），英文 `Today` 比「今天」宽 —— 要确认它没被 `fitXY` 压变形、也没把日期挤走。
- **一格一格对**：翻到 5 行月与 6 行月各看一次（今天那一格的**块尺寸**按行数反推，5 行月的格子高 18%，出错就在这一档）。
- **Dart 侧的护栏必须继续绿**（它们是这个子系统唯一能自动跑的东西）：
  `widget_fixed_cards_guard_test.dart`（42 槽位 id、`addView` 前的 `removeAllViews`、三份 info.xml、翻月锚点与箭头）、`widget_layout_whitelist_test.dart`（布局里不许出现白名单外的视图类 —— 本轮新增的只有已经在用的 `FrameLayout` / `ImageView`）、`widget_snapshot_test.dart`、`widget_today_card_staleness_test.dart`、`widget_push_dedup_test.dart`。
- **新增护栏**（本轮要补的）：
  - 两张 cell 布局里都有那个块 `ImageView`，且它的 id 与 Kotlin 里引用的逐字一致（扫源码，同 `widget_fixed_cards_guard_test` 的家法）；
  - 四张卡底 / 格子资源文件存在，且浅深两档成对（少一张就是某档静默画不出来）。
- `flutter analyze` 0 error / 0 warning、`flutter test` 全绿、`flutter test tool/visual/` 全绿（**Kotlin 改动不该动到那 255 张图**——工装里一个 RemoteViews 都没有）。

## 7. 本轮不做的，与单独记一笔的

- **卡片投影（浮起）**：App 的卡有一圈 `black 10% blur 28 offset(0,10)` 的投影，桌面上要加就得**在卡片外面留一圈透明边**（位图或 `elevation` 都需要空间），代价是内容区变小。**先做无投影版本、出图再看**，觉得还不够浮起再单独立项。
- **今日卡的「其他班组」**：App 是胶囊，桌面是圆点 + 文字。本轮**不动**（它是另一处独立改动，且要连带量文字宽度）。
- **日期行补「星期日」**：快照里已有 `d.weekday`，技术上是一行拼接。本轮**不动**，理由同上（要防它把「今天」徽章挤走）。
- **系统切深色后小组件不重画**：2026-10-11 真机上观察到 —— 系统切到深色之后，桌面那张卡**不会自己重画**（它要等 App 推一次新快照；我那边是靠翻一下月历的箭头逼出来的）。**这条证据还不干净**（当时 App 的主题开关被我误点过），**单独立项复验**，不要塞进本轮。
