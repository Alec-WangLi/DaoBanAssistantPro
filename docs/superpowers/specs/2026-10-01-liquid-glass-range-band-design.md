## 1. 目标

长按拖选一段日子时，今天画的是**逐格各一块 14% 圆角方**（`day-range-N`）——
格子之间有 4px 缝，**缝不属于任何一格**，所以「连成一条」在今天的结构里做不到。

这一轮把它换成一枚**真的水带**：同一行里是整条（缝一起盖住）、两个真端头是圆的、
按住时长按那一刻它像水一样漫上来，拖动时**末端淌到新的一格**、探进哪一格哪一格的字被挤一下，
一圈彩色的光跟着末端的方向亮。

## 2. 用户拍板的（不可自行更改）

1. **跨周 = A「每行一段，只有两个真端头是圆的，跨行处切平」**（2026-10-01 在 A/B/C 三张对照图上选的）。
   B（每行一枚胶囊）读成「两枚药丸」，与今天的「一排小色块」只差粒度，没解决「连成一条」；
   C（沿行缝拐回来）放大是一道横线，且加厚就会盖到区间外的格子 —— 两条都写在 §9。
2. **「一整条连续的水带」**（更早一轮已定）。
3. **标准档那棵树逐像素不变**（今天那排 14% 小色块原样留着，`day-range-N` 那些 key 也照旧）。

## 3. 范围与档位

**只作用于液态档。** 标准档连一层都不加（`liquidGlassActive` 只在 `calendar_screen.dart`
那一个调用点读 —— 判据名单**不变**，新抽出来的两个文件都不读档位）。

判据要读 `liquidGlassActive.value` 的地方只有一处：`_buildGrid` 里「画不画这条带子」的分叉。

不必每次去挂整张日历。widget 那层只剩「弹簧 + 材质」。

## 4. 几何与算式（逐条钉死）

### 4.1 区间 → 每行一段

- 输入是两个日期（`from ≤ to`，调用点先归一序）与当前月。槽位 `slot = _leading + day - 1`，
  `row = slot ~/ 7`、`col = slot % 7`。
- 逐天过一遍，按行分组，取每行的最小 / 最大列 → `(row, firstCol, lastCol)`。
  区间是连续的，所以**每行内部的列也一定连续**（不需要处理跳格）。
- 单天 → 一行一段（`firstCol == lastCol`）。

### 4.2 每段那个矩形

| 边 | 值 |
|---|---|
| left | `_hPad + firstCol·cellW + _cellInset` |
| right | `_hPad + (lastCol + 1)·cellW − _cellInset` |
| top | `_weekdayH + row·cellH + _cellInset` |
| bottom | `_weekdayH + (row + 1)·cellH − _cellInset` |

内缩与卡片**同源**（`_cellInset = AppTokens.gapHair`）—— 与那枚块同一个道理：差一档就与卡片
的边对不上。**相邻两格之间的那 4px 缝因此被这一段盖住**（这正是「连成一条」的几何来源）。

### 4.3 四种角

| 位置 | 半径 |
|---|---|
| 区间**起点**那一侧的上下两角（`from` 所在的段、靠外那一侧） | `AppTokens.radiusM`（16） |
| 区间**终点**那一侧的上下两角（`to` 所在的那一段） | 同上 |
| 跨行处那两头（上一段的末端、下一段的起端） | **0（切平）** |

**端头半径先取 `radiusM`（16）**，与卡片、与那枚块**同一个数**。

⚠️ **这一处设计稿与图不一致，以图为准**：探针那张 A 版（你选的就是它）端头就是 16，
而同一条设计里我写的是「圆到底（内盒的一半，像管子口）」—— 两种同时出现过，**你看的图是 16**。
这一版按 16 发，理由是它与卡片、与那枚块同源：长按起手那一帧带子只有一天、会与那枚块叠在
同一格上，两枚圆角不一致时像错位（v0.7.3「四个角露月牙」是同一类）。**要更圆就改一个数**
（§11），真机上看着定。

### 4.4 末端是**连续**的

- 带子的两个端头里，**只有会动的那一个**（跟着手指的那个 = `_rangeFocus`）是连续的：
  它在自己的行里是一个小数位置（列 + 小数），走一条弹簧朝吸附到的那一格淌过去。
- 另一头（长按落下的那一格）**不预测、不动** —— 用户往回拖时角色互换：起端跟着手指、末端固定。
- **行是离散的**：末端跨到下一行时形状结构变一次（上一段补齐到行尾、下一行新起一段）——
  这是月历本身的结构（跨周不是相邻格），不是可以插值的东西。

### 4.5 形变与光

- **末端沿运动方向鼓出去一点**（≤ 8px，走弹簧，避免「啪」）：`tipX += bulge`。
- **高度不动**。这一条是**有意的、与那枚块不同**：带子是**一条渠道里的水** ——
  它的上下被这一行夹住（一变形就会露出格子的上下沿），所以形变只能出现在末端。
- **彩边**：沿用第五轮那套（四层光谱共用的 `spectralSweep`），亮 **末端的速度方向**
  （`motionAngleDeg = atan2(vy, vx)`；门以下保持上一次的方向，不转回去）。
- **只有流动的那一端挤字**：`lensCenter` = **末端此刻淌到的那一点**（不是它吸附到的
  那一格的中心 —— 实施时订正：场只够到一格的半径，而**格中心的 `t` 恒为 0**，
  场落在格中心上等于一格都不挤）。带子内部不动 —— 那里面是**已经圈住**的日子，
  把它们也挤了就不像「水正在漫过来」。

### 4.6 升程（按住 / 松开）

- 与那枚块同一套：按下走 Lift、松手走 Unlift。**长按落下那一刻整条水带漫上来**（升程 0 → 1，
  四面各鼓 `protrude`、底下浮起阴影），松手落回去。
- 与那枚块**共用同一个 `LiquidLensMetrics` 量级**（每侧 6 / 纵向 12），只是这次的「控件」是整条带子。

## 5. 共享件要抽的那一维（`liquid_lens.dart`）

那四层光谱（环 / 两层光晕 / 外溢）与浮起阴影现在**全部绑在 `LiquidLensShape.toPath()` 上**。
带子要复用它们，就得把「轮廓」这一维抽出来。

**做法**：`LiquidLens` 收一个 `LiquidLensOutline`（一个能给 `Path`、并带着 `motion` /
`motionAngleDeg` / `rimScale` 这些**与形状无关的表现参数**的东西）；`LiquidLensShape` 实现它，
于是**四个既有调用点一个字都不用改**。

- 默认路径**逐字不变** → 底栏 / 分段器 / 开关 / 响铃药丸**逐像素不变**（§6 第 1 条验收）。
- 带子那一层给的是自己的 `Path`（多段圆角矩形的并集），表现参数照传（`motion` 来自它自己的
  那条弹簧、`rimScale` 按带子高度取）。
- ⚠️ **这一维是给「轮廓不是单凸形状」的东西用的**，不是给「想换颜色」用的 —— 别把别的东西也塞进来。

**顺序**：这一抽是**第一步**，抽完要先证明四个既有调用点逐像素不变，再动带子
（v0.10.9 那次「先抽共享件、再推广」的同一条路）。

## 6. 交互（一处都不改）

- 长按进入多选态（`Haptics.modeEnter()`）、拖动时**每进一格震一次**（`Haptics.select()`）、
  松手弹同一个选择层、不跨月、空白表方案不入口 —— 全部沿用，一行不改。
- **状态仍是吸附到格**（`_rangeAnchor` / `_rangeFocus` 都是整格）：末端「淌过去」**只是观感**，
  不改变任何语义 —— 触觉那条契约靠的就是「进一格响一次」。
- 那枚单格选中块照旧（长按起手时它会按原来的规矩熄掉 `_pressed` / `_dragActive`）；
  带子画在它与网格之间（网格 → 带子 → 那枚块）。

## 7. 验收

1. **标准档逐像素不变**：在开工前的提交上开临时 worktree 渲一遍 `tool/visual` 全套当基线，
   改完重渲逐张比（`scripts/diff_visual.py`）。**标准档一张都不许变**。
2. **液态档那屏**：新增 `52_calendar_range_band`（拖选到一半、跨周那一帧）——
   静止帧拍不到它，必须真长按真拖。另出一条 GIF。
3. **共享件那一抽不改变任何东西**：四个既有调用点的屏（底栏 / 分段器 / 开关 / 响铃药丸）
   在抽完之后**逐像素相同** —— 这一步单独跑一次比对，再往下做。

## 8. 非目标（这一轮明确不做）

- **跨月拖选**：手势语义会变怪（要翻页才能圈），v0.8.1 已否。
- **改吸附语义**（末端 1:1 跟手、松手再吸附）：触觉那条「进一格响一次」靠的就是逐格状态。
- **改选择层 / `adjustDays` / 按天覆盖那套链路**：一个字不动。
- **带子高度的形变**：见 §4.5 的理由（渠道里的水）。
- **单天那一帧的带子**：长按刚落下的那一帧区间只有一天，它与那枚块叠在同一格上 ——
  这一帧**照常画**（形状与块同源，不打架），但**不做任何额外特效**。

## 9. 做过又被看图否掉的（别照搬）

- **C「沿行缝拐回来」**：我原本以为这是最像「一条连续的水带」的一版。放大之后是一道
  **4px 厚、还带 2px 描边**的横线，横在两周之间像一根尺子；而要它像水就得加厚，
  一加厚就盖到区间之外的格子（行缝上面是上一周没选的日子、下面是下一周没选的日子）。
  **结论：跨周不做连接。**
- **B「每行一枚胶囊」**：读数是「两枚药丸」，与今天「一排小色块」只差粒度 —— 没解决「连成一条」。

## 10. 风险与代价

- **共享件那一抽是这一轮唯一的地基改动**：`LiquidLens` 的四个调用点有「逐像素不变」的验收，
  抽错了会一次性影响底栏 / 分段器 / 开关 / 响铃药丸四处。靠 §7 第 3 条那一步单独比对兜。
- **每帧重建**：拖选时今天本来就是整棵网格 `setState` 重建，本轮新增的是一条路径（几十个点）
  与四层材质。**要量一次帧时间。**
- **带子的面积比那枚块大得多**：本体那层是 `ClipPath` + 半透明填充，四层光谱是描边 ——
  面积大了之后「彩边是不是糊成一片」只能看图（§11 有一个数可调）。
- **末端淌过去**的首帧与「吸附到格」的触觉可能错开半格（触觉在进格那一刻发，形状还在路上）——
  这是**有意的**（声音/触觉该在信息发生的那一刻给），但要确认它不读成「迟了一拍」。

## 11. 未定项（要你拍板 / 真机上看）

1. **端头半径**（§4.3）：先按 `radiusM`（16，就是探针那张图上的数）发。
   真机上觉得不够「水」就往内盒的一半（40.5，真正的管口）加 —— 一个数。
2. **末端鼓出的上限**（§4.5 的 ≤ 8px）与那条弹簧的参数：手感数，先按 8 发。
3. **材质的浓度**：那枚块的本体是 `[accent 0.22, accent 0.10]`，带子面积大得多，
   同一档可能偏重 —— 先照抄，看图再收。
