# v0.12.0 设计语言收口 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把全 app 八处「同一个东西长得不一样」收成一套，补掉上一版的两条 Minor，出 `0.11.18` 测试版；用户真机验完再收口成 `0.12.0` 并做门面与动图。

**Architecture:** 每一条都先**抽共享件**、再替换调用点 —— 先让共享件上线并证明既有画面**逐像素不变**（纯搬运），再一处一处换。这样「搬运错了」与「换错了」永远分得开。任务 1~10 是代码，11 是发测试版，12 是（用户验过之后的）正式版门面。

**Tech Stack:** Flutter 3.47 / Riverpod / 设计令牌 `AppTokens` / 静态 i18n `L10n` / `flutter_test` + 视觉工装 `tool/visual/` + 出帧管线 `tool/gif/`。

**Spec:** `docs/superpowers/specs/2026-10-13-v0120-design-sweep-design.md`

## Global Constraints

- **中英双语**，文案只有 `core/l10n.dart` 一处写。
- **设计令牌是唯一来源**：界面层不写 `fontSize:` / `fontWeight:` / `circular(<数字>)` / `Color(0x…)` / `Duration(milliseconds:)` / `Icon(size:)` 字面量，由 `app/test/design_tokens_test.dart` 守门（间距常量要落在 4px 栅格）。
- **样式一律白名单**：换件时用 `AppTokens` 的角色名（`sectionTitle` / `titleStrong` / `labelStrong` / `rowPrimary` / `rowSecondary` / `labelSecondary` / `microStrong`），**不许就地写一个「最像的」值**。
- **不许跑 `dart format`**（工具链是另一套风格，一跑就重排整个文件、制造几百行无关 diff）。只跑 `flutter analyze`。
- **每抽一个共享件都要先证明既有点位逐像素不变**：`python scripts/diff_visual.py <before-dir> <after-dir> --threshold 0`（它吃两个目录、逐张比同名文件）。
- **护栏必须反向验证**（这个仓库的铁律）：新加的用例要能红，改回旧行为立刻红。
- **每改一处界面都要出图看**，并把新界面 / 新状态补进 `app/tool/visual/visual_screens.dart`。
- 验收线：`flutter analyze` 0 error / 0 warning；`flutter test` 全绿且**只增不减**（当前 **1026**）。
- 测试命令：仓库根 `bash tools/flutter-test.sh [路径]`（本机 bash 下等价于 pwsh 那边 dot-source `tools/build-env.ps1`）。

## Review Focus

这五类是这个 spec 暗示了、但没有任何一个任务的用例会自己去覆盖的。每一条都归到拥有那段代码的任务里，用那条任务自己的步骤风格补一条用例：

1. **弹层头部加高之后，小窗 / 手机横屏 / 特大字号下的弹层**：新加的把手 + 分隔线让头部变高，取色层那种本来就吃键盘高度的弹层最危险。（归 Task 3）
2. **把水波纹换成玻璃按压缩放之后，长按与拖拽**：`InkWell` 会参与手势竞技场，而日历上那两处就在网格的长按拖选链路上。（归 Task 6）
3. **小节标题从 13 号变 16 号之后，「我的」页在窄屏与特大字号下的排版**：字变宽变高，「权限」那一节的长行可能被挤。（归 Task 1）
4. **排班管理页那颗按钮从列表里搬到悬浮层之后，列表最后一行的让位**：那一页此前**没有**这类几何用例（待办页与闹钟页各有一组）。（归 Task 9）
5. **动图必须是真实录制**：没有代码可测，判据只有「真的在动、且是从工装渲出来的帧合成」。（归 Task 12）
