# 倒班助手Pro v0.8.0 更新说明

> **正式稳定版**，归纳 v0.7.1 ~ v0.7.5 五个测试版的全部更新。
> 配图在 `docs/images/v080-*.png`（发帖时按下面的顺序传上去就行）。

![倒班助手Pro v0.8.0](images/v080-cover.png)

从上一个正式版（v0.7.0）到现在，改动几乎都来自你们的反馈 —— 尤其是「闹钟到点只响、不弹界面」那条，这次终于查到了真因，也终于修好了。

---

## 一、小米机型：锁屏 / 后台真的能弹出响铃界面了

**先认个错。** 之前版本里我写过「小米/华为免解锁弹全屏受系统限制，要解锁之后才能关闹钟」——**那句话是错的**。当时没接真机调试，是照着网上说法猜的。

这次把手机连上电脑、一步步跟日志，查清了：真因是小米把**「后台弹出界面」**（系统英文界面里叫 *Open new windows while running in the background*）单独设成了一项权限。不开它，MIUI 会**静默拒绝** App 从后台弹出界面 —— 闹钟照响、屏幕也亮，界面就是不弹；连通知那条全屏通道也一起被拒，所以没有「靠通知兜底」这条路。

它和另外两项**不是一回事**：

| 权限 | 管什么 |
|---|---|
| 显示悬浮窗 | Android 原生的「允许后台启动」，通用 |
| **后台弹出界面**（小米） | 退到后台后能不能把界面弹出来 |
| **锁屏显示**（小米） | 锁屏时能不能顶掉锁屏显示内容 |

**锁屏要弹出响铃界面，后两项缺一不可。** 我上次就是只开了一半（以为开了「后台弹出界面」，其实开的是「锁屏显示」），所以退后台还是不弹。

![小米机型锁屏弹出响铃界面](images/v080-miui-ring.png)

实测（Redmi K90 Pro Max，Android 16）：两项都开上之后，**退到后台会自动拉回前台，锁屏会点亮屏幕并顶掉锁屏**，直接弹出响铃界面。上图左边是没开时的样子，右边是开了之后。

这一版把这两项都放进了「我的 → 权限」（仅小米机型显示），点「去查看」直接跳到系统的权限页 —— 这项权限系统不提供状态查询，所以只能做跳转引导，不假装能检测。

## 二、重启手机后，闹钟和待办提醒都不再丢

以前重启手机，系统会把所有排定的闹钟清空，**要等你下次打开 App 才会重排** —— 也就是说重启之后、下次开 App 之前，所有闹钟都是哑的。

现在排定闹钟与待办提醒时会同时落盘一份清单，开机后自动排回去：

- 每天 / 每周的闹钟顺延到下一次；一次性、还没到点的按原时刻排回；
- **关机期间已经错过的一次性闹钟不会补响**（半夜的闹钟在早上开机时突然响，比不响更糟），错过的待办提醒也不会补发；
- 不需要新权限，用的就是已声明的「开机启动」。

![重启后自动排回](images/v080-reboot.png)

真机实测的数字就是上图那样：重启前 30 条闹钟，重启后系统清空，**解锁的那一瞬间 30 条全部排回**，时间跟重启前一模一样。

## 三、权限页重做

原来的权限卡有两个毛病：一是只说「开没开」，不告诉你**不开会怎样**；二是中文名起错了一处 —— 那行「后台弹出界面」其实对应的是 Android 的「显示悬浮窗」，套用了小米的说法，让人以为小米那项权限已经覆盖了（我上次就是被它误导的）。

![权限页重做](images/v080-permissions.png)

现在按用途分三组（基础提醒 / 弹出响铃界面 / 后台与开机），每行直接写「不开会怎样」；「显示悬浮窗」正名并挪出「锁屏」组；小米机型补上「锁屏显示」—— 与「后台弹出界面」并列，因为它们的症状不同（退后台不弹 vs 锁屏不弹），你能各自对号入座。

## 四、修掉一个隐患，以及一批老问题

**响铃结束后，App 主界面会留在锁屏上**（安全隐患）。根因是「可以盖在锁屏上」这个状态**只有打开、从来没撤回过**，闹钟响过一次之后就一直生效，直到进程被杀 —— 也就是说锁屏下任何人都能直接看到并操作这个 App。现在响铃一停就撤销，关掉闹钟回到的就是锁屏。顺带堵上同一条隐患的另一个入口：响铃期间按返回手势不会退回主界面了。

其余这一版修好的：

- **关掉闹钟后重新进入 App，响铃界面又弹一次、而且没有声音** —— 界面被一个陈旧的暂存值唤醒，实际上根本没有闹钟在响
- **日历里选中那天的滑块没把格子盖住** —— 滑块与格子的圆角差了一档，四个角会露出底下的卡片

![日历滑块对齐](images/v080-calendar.png)

- **「添加 / 编辑待办」填好了点按钮没反应** —— 键盘弹起时按钮被挤出了卡片
- 日历格子：两个字的简称不再被省略成「上…」，日期回到居中
- 待办提醒真正生效（此前设了提前提醒也不会有任何反应），并新增「联动闹钟」
- 闹钟铃声可以从手机里自选（内置 / 系统 / 自己的音频文件），文件损坏时自动回落到内置铃声

## 已知限制（写在明面上）

- **关机的时候闹钟不会响**：关机状态下没有任何应用在运行，这一点绕不过去。
- **重启后要等手机第一次解锁**：这是 Android 的限制 —— 设了锁屏密码的设备，「开机完成」这个广播要等首次解锁才发给应用。所以「半夜重启、之后一直没解锁」那一段里闹钟仍是哑的。
- 小米机型「自启动」不开的话，重启后闹钟要等下次打开 App 才恢复。
- 法定节假日数据目前只覆盖到 2026-12-31（内置的是 2025/2026 两年的国务院放假安排，次年的通常每年 11 月才发布）。
