v0.13.19 测试版：统计页三处顺手，加一轮图表精修

- 年视图里点顶上的年份，直接弹出年份滚轮 —— 跨十年不用再一路点箭头
- 翻月 / 翻年 / 「今天」，以及年视图点某个月，都会震一记；已经停在本月 / 今年时不震
- 期间条那三颗玻璃钮亮了一档；左右箭头的颜色也修了 —— 深色下它们原本被画成黑色，「看着有点暗」就是它
- 统计页统一「图标在前」：月 / 年分段、四格指标、每张卡片的分节标题、出勤亮点的四行，都带上了语义色图标
- 图表精修：环图加了底轨、圆头分段与真实缝隙（某个月只有一种班、甚至一天的那种小段，也不会被缝隙吃掉）；出勤构成条分段留缝；月度工时柱改成底轨 + 顶圆角渐变柱 + 均值虚线（只统计有工时的月份）+ 当月高亮，切年时从基线长出来
- 请假构成每个类型多了一条占比细条；统计口径补了一条「月度均值线只统计工时 > 0 的月份」

这一版只动统计页，排班、闹钟、待办的数据与行为都没变，直接覆盖安装即可。
