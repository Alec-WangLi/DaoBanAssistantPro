v0.14.0 正式版：多了统计、请假加班和数据备份，闹钟也更不容易丢

这一版把 v0.13 的二十七个测试版收口，是三样新东西 + 一条老命脉的加固。

- 新：统计页。月 / 年两种视图，实际在岗、正常工时、上班休息天数、请假、加班、夜班、最长连班连休；环形图 + 出勤构成条 + 月度工时柱，全部自绘，不引第三方图表库
- 新：请假与加班。日历上任意一天记时长、类型（年假 / 事假 / 病假 / 调休 / 其他，也能自己起名）和备注；整天请假会自动压掉那天的班次闹钟
- 新：出勤表导出 CSV。自己选起止日期和字段，Excel 直接打开，拿去算工资或交班
- 新：数据备份。「我的 → 数据备份」导出 .dshbackup，换机或重装后导入即恢复（排班、待办、模板、闹钟、设置、你保存的铃声）
- 闹钟加固：重排改成先排后清（不再有几秒钟一条闹钟都没有）；每 6 小时巡检一次自动补回；闹钟页顶上多一行「下一次响铃」；「查看日志」改成整页，能按天翻、搜索、一键导出诊断包
- 权限页按品牌给入口：三星「休眠应用」、一加 / OPPO「自启动」，直接跳到系统的设置页
- 顺带：法定节假日自动更新、触觉走设备自己的预定义效果、日期弹层点年月标题直接跳月、深色下不再有黑压压的图标、底栏滑块跟手
- 修：HarmonyOS 3.0（荣耀 10、畅享 20 Pro 一类）一开就闪退；系统文件管理器选铃声返回后没反应；重复待办改「从这天起」不生效；导入备份后点重启拉不起来

数据库会从旧版本自动升级（新增请假表、调班备注表），原有排班与待办不受影响，直接覆盖安装即可。
