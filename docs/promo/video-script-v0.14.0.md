## 重新出片（改了界面或文案时）

```bash
# 1) 逐帧渲染（9 场约 3 分半；只重跑改过的那场：--plain-name 待办）
bash tools/flutter-test.sh tool/promo/render_promo_video_test.dart
# 2) 拼片（片头片尾卡自动生成，字幕在这里烧）
python scripts/make_promo_video.py
# 3) 配音（只合成缺的那几条，已有的 mp3 直接复用）
python scripts/make_promo_voice.py
```

- 帧落 `app/build/promo-video/frames/`（约 545MB，gitignore）。
- 场次名在 `render_promo_video_test.dart` 的 `scene:` 与 `scripts/make_promo_video.py` 的
  `SCENES` 两处，**改名要一起改**。
- 尺寸定在 `kVideoSize = 432×768`（dpr 2.5 → 1080×1920）。换成 360×640 会被底栏信息卡
  切掉日历最后一行 —— 那是 3 倍密度机型的 dp，高度不够。
- 改了某一句口播想让它重新合成：删掉 `app/build/promo-video/voice/<音色>/` 里对应的 mp3。

## 配音：edge-tts

`scripts/make_promo_voice.py`，用 **edge-tts**（Microsoft Edge「大声朗读」的公开接口）。

选它的理由：免费、不要 API key、中文音色接近商用。对比过的几条路 ——

| 方案 | 代价 |
|---|---|
| **edge-tts**（已用） | 免费；走公开接口，不保证长期可用 |
| Azure 语音 | 质量同级甚至更好、支持 SSML 逐字调，但要订阅 + key + 计费 |
| 火山 / 阿里云 TTS | 中文最自然，要实名 + 计费 |
| 剪映「文本朗读」 | 白嫖最省事，但得手动一条条贴，改一次重来一次 |
| GPT-SoVITS / CosyVoice | 能克隆自己的声音，要 GPU 和几十 GB 模型 |

三个音色各出一条成片，挑一个上传：

| 后缀 | 音色 | 适合 |
|---|---|---|
| `-yunxi` | 云希 · 男声，阳光 | 开发者自述、偏亲切（默认） |
| `-yunjian` | 云健 · 男声，有力 | 产品介绍，节奏更冲 |
| `-xiaoxiao` | 晓晓 · 女声，温和 | 泛用户、教程向 |

换音色：`python scripts/make_promo_voice.py --voice yunjian`；看全部：`--list`。

口播稿在同一个文件的 `VOICEOVER` 里，**比字幕短**：字幕回答「现在看的是哪一项」，
口播回答「为什么这件事值得看」，两边一样的话听着像在朗读页面。脚本会逐条报
「说到第几秒」，一条压到下一句头上会打 ⚠️ —— 那时候要改的是稿子，不是语速。

## 还差 BGM

现在只有人声。要贴 BGM，一条命令（把 `bgm.m4a` 换成你的曲子）：

```bash
ffmpeg -i daoban-...-yunxi.mp4 -i bgm.m4a \
  -filter_complex "[1:a]volume=0.18,afade=t=out:st=40:d=4.8[b];[0:a][b]amix=inputs=2:duration=first[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k out.mp4
```

0.18 是压到人声底下的经验值（约 -15dB）；人声一响 BGM 不躲的话，听着像两条音轨各说各的。

## 平台规格

| 平台 | 规格 | 备注 |
|---|---|---|
| 抖音 | 1080×1920 / 30fps / mp4 | 支持无音轨，但上传后建议有 BGM；时长 40s 属于「完播率友好」区间 |
| 小红书（视频） | 1080×1920 或 3:4 | 本次走图文，视频版可直接用这支 |

## 字幕怎么烧的

**烧死了**，在 `scripts/make_promo_video.py` 的 `SCENE_CAPTIONS` 里 —— 改文案不用重渲帧，
重跑一次拼片（约 10 秒）就行。

版式是**画中画**：模糊放大的自己当底，中间放清晰画面（842×1496），下面一条字幕带。
为什么不直接满屏烧：

- 抖音、小红书自己的 UI 压在下 250px，满屏字幕要么被盖住，要么压住 App 的信息卡；
- 画中画把 App 收窄 22%，但换来一条永远干净的字幕带，走路、地铁上都能看清。

字幕带两行：上面那行是场次名（① 排班日历…，整场常驻），下面那行随动作变。
白字加黑描边而不是方框底 —— 方框会把这条本来就不宽的带子塞满。

想关掉（要满屏原画）：`python scripts/make_promo_video.py --no-captions`。
