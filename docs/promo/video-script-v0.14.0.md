## 重新出片（改了界面或文案时）

```bash
# 1) 逐帧渲染（9 场约 3 分半；只重跑改过的那场：--plain-name 待办）
bash tools/flutter-test.sh tool/promo/render_promo_video_test.dart
# 2) 拼片（片头片尾卡自动生成）
python scripts/make_promo_video.py
```

- 帧落 `app/build/promo-video/frames/`（约 545MB，gitignore）。
- 场次名在 `render_promo_video_test.dart` 的 `scene:` 与 `scripts/make_promo_video.py` 的
  `SCENES` 两处，**改名要一起改**。
- 尺寸定在 `kVideoSize = 432×768`（dpr 2.5 → 1080×1920）。换成 360×640 会被底栏信息卡
  切掉日历最后一行 —— 那是 3 倍密度机型的 dp，高度不够。

## 后期怎么贴 BGM 与口播

**剪映（推荐，最省事）**：新建 9:16 项目 → 导入这支 mp4 → 「音频」里挑 BGM（音量压到
-18dB 左右）→ 「录音」按上表时间码念口播 → 导出 1080×1920 / 30fps / 高码率。

**ffmpeg 一条命令**（已有配好音的 wav/mp3 时）：

```bash
ffmpeg -i demo.mp4 -i bgm.m4a -i voice.wav \
  -filter_complex "[1:a]volume=0.18[b];[2:a]volume=1.0[v];[b][v]amix=inputs=2:duration=longest[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k -shortest with-audio.mp4
```

## 为什么画面里没有烧字幕

口播由你录，字幕跟语音走比跟画面走更合拍；而且烧死的字幕改一句就得重渲整片。
真要上字幕，在剪映里「识别字幕」一次性生成，改起来是拖一下的事。
