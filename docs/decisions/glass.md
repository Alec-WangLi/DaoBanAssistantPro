## 原文留档 · v0.12.8：`ImageFilter.shader` 的 uniform 0 不是你的

> 这条原先只活在 `AGENTS.md`「版本号规则·最近历史」那一行里，删除那段之前先落到这里。
> 一句话：**引擎会把第 0 个 vec2 uniform 覆写成「输入纹理尺寸」**，而滤镜链上游的高斯模糊会对称外扩纹理 —— 于是「按容器尺寸归一化」的着色器把「容器 + 外扩」当成容器，折射带整条落在容器外，全部走 early return，**真机上等于纯模糊，一个像素都没弯过**，而本地 `flutter test` 走 Skia 根本渲不出来。修法：容器尺寸另立 `uniform vec2 uContainer`（Dart 灌 floats 8/9），几何在容器空间、采样在纹理空间。
