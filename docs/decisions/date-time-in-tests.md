# 决策与坑 · 用例里的日期与时钟（`appNow()` / `kAnchor` / 静默空转）

> 2026-11-06 批次 1a~4 收口时写下的。面向**下一个要写日期相关用例的人**。
> 逐条结账与原始日志在 `docs/decisions/evidence/2026-11-06-date-audit/`（矩阵、失败名单、每个数字怎么算出来的都在那里）。
> 相关实现：`app/lib/core/clock.dart`（`appNow`）、`app/test/support/fixed_clock.dart`（`kAnchor` / `useFixedNow()`）。

## 三条最要紧的结论

1. **② 静默空转比 ① 会红更危险。**
   ① 会红，红了就有人修；② 绿着，绿得让人以为测过了。这次 5 条 ② 里有 **3 条**是靠「把时钟钉住之后突然红了」才暴露的 —— 在此之前它们一直是绿的。

2. **清点必须「钉住时钟前 / 后」各跑一遍。**
   只看一遍永远发现不了 ②：改前那一遍它绿（真实时钟碰巧对上），改后那一遍它才红。只跑改后那一遍，你只会看到「全都绿」，然后写下一个错的结论。

3. **③「本来就自洽」不等于「没问题」。**
   它只说明在**试过的六个锚点**（01-01 / 01-30 / 01-31 / 02-27 / 10-14 周三 / 12-31）下都绿。闰年 2 月 29 日、跨年那一格、以及时区，这三类形状**仍未覆盖**。

## 可操作的规矩（写新用例时照着做）

1. **新用例里不许出现 `DateTime.now()` / `TimeOfDay.now()`。**
   唯一豁免是响铃界面显示「现在几点」那一句（`app/lib/features/alarm/alarm_ringing_screen.dart:196` 的 `ringClockText(TimeOfDay.now())`）—— 它的语义就是真实此刻。
   要「今天」用 `appNow()`；要固定的一天用 `kAnchor`（`app/test/support/fixed_clock.dart`，= **2026-10-15 周四**：国庆在月内、有 31 号、5 行月，三件事同时成立）。

2. **需要特定月份形状的用例，自己把时钟钉到那个月。**
   例：需要「当月有法定节假日」就 `_pinNow(DateTime(2026, 10, 3))`，并在 `addTearDown` 里还原（固定日期不许指望真实月份给你）。整文件都要钉就在 `main()` 里调一次 `useFixedNow()`。

3. **不许写「离今天够远」这种按真实时钟挑目标的代码。**
   反面例子：`app/test/calendar_frame_budget_test.dart` 的 `_farDay()` 读真实时钟挑一格，网格画的却是锚点那个月 —— 真实今天是 8 号或 22 号时挑中的正是它自己，滑行不起，断言恒过（每月 2 天、约 6.5%，永不报错）。改成按 `appNow().day` 算，并加前置断言：目标离今天不足 5 天就报「这条空转了」。

4. **断言里不许写死几何。** 别写 `Offset(0, 60)`、`day-card-31`，也别假定「当月必有节假日 / 必有 31 号 / 一定 5 行」。
   要拖动就量格子实际尺寸（`cell.height`、`cell.width * 0.6`）；要末格就按当月天数算（`DateTime(y, m + 1, 0).day`）；承认的边界要**写出算式**（例：6 行月滚的量 = `weekdayH + 6×58 − 可用高度`），不许放宽成「允许滚」。

5. **`didExceedMaxLines` 在多行文本外套 `FittedBox(scaleDown)` 时是死路。**
   挤了不报错，只悄悄缩小。这种地方要量缩小比例（`calendar_header_fit_test.dart` 的 `_shrinkOf()`：中文 1.0000、英文 `May 2026` 0.9941）。

6. **时钟入口只许经 `core/clock.dart`，由两条护栏守着：**
   - `app/test/clock_guard_test.dart` —— `app/lib` 里除 `core/clock.dart` 自己外没有 `DateTime.now`；
   - `app/test/time_of_day_guard_test.dart` —— 除响铃那一句外没有 `TimeOfDay.now`。
   新增任何「读当前时刻」的入口，同时加护栏；不改护栏就等于没改。

## 怎么做一次清点（实测流程）

1. **锚点扫描**：只改 `app/test/support/fixed_clock.dart` 的 `kAnchor`，其余一个字不动，跑全套。这次的结果：`2026-01-31` 全绿、`2026-02-28` 红 2、`2026-03-01` 红 8 —— 红的全在没碰过的三个日历文件里，说明锚点是活的、断言不空转。
2. **两遍跑**：HEAD 版表达式 + 敌意锚点（用例造数据用真实今天、App 以为的今天被改掉）跑一遍 → 会红的 ① 全跳出来；钉住之后跑一遍 → 全绿才算修好。
3. **分类只准分三档**：① 会红 / ② 静默空转 / ③ 本来就自洽。**不许把 ② 当 ③ 放过。**
4. **验反证的姿势**：先把整个文件 `cp` 到 `work/tmp/` 备份，还原一律 `cp` 回来。禁止在别人有未提交改动的文件上跑 `git checkout` / `git restore`。
