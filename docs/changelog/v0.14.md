- **v0.14.4（测试版 · 闹钟渐响 / 导出日期 / 底层大修）**
  三件事：一条用户反馈、一个 issue、一次停在工作区里的依赖升级 —— 0.14.3 从未提交，一并收进这一版。

  **① 闹钟渐响（用户反馈）**：`AlarmSound.kt` 起播时按开关做 0 → 1 的音量斜坡（每 100ms 一档、
  20 秒到位）。两条响铃链路（前台 `MainActivity.startAlarm`、后台 `AlarmRingService`）共用同一个
  `Playback` 句柄；停止统一走 `Playback.stop()`（先摘计时器再 release），`VIBRATE_ONLY` 天然跳过，
  试听走的是另一条播放器、不受影响。开关在「我的 → 渐响」，默认关；prefs 键 `fadeInRingtone`
  （原生读 `flutter.fadeInRingtone`），由 `alarm_fade_in_test.dart` 扫源码守两侧一致。
  顺带修掉 `AlarmRingService.onStartCommand` 重入时旧播放器没停的隐患（加了渐响之后会是两条 ramp）。

  **② issue #13（统计导出日期）**：默认区间夹到今天（`stats_screen._openExport`），`_pickTo` 补
  `lastDate`；选择器本身早就按 `firstDate` / `lastDate` 置灰禁点（`glass_pickers.dart:246-247`），
  不用改。区间整个落在未来（翻到下个月）时两头一起夹，避免 `from > to`。新增 1 条 widget 用例。

  **③ 底层大修**：flutter_local_notifications 17 → 23、drift 2.20 → 2.35、sqlite3 2.9 → 3.5、
  AGP 9.1.1、compileSdk 37。v23 把平台接口改成延迟初始化，`resolvePlatformSpecificImplementation`
  在没有原生实现的环境（widget 测试）里抛 `LateInitializationError` —— 全套 39 条用例因此变红。
  收进 `_androidImpl()`（拿不到当「没实现」）与 `_cancelAllNotifications()`（`Error` 不重试），
  重排预算回到 12 次以内。`appBuild` 也补齐到与 pubspec 一致。

  **数字**：单测 1449 → **1452**；`flutter analyze` 0 issue；视觉工装 1719 条全过；
  版本 `0.14.3+218`（未提交）→ **`0.14.4+219`**。

- **v0.14.0（正式稳定版 · 归纳 0.13.1~0.13.27 二十七个测试版）**
  这一版是三件事的收口：**统计页**、**请假 / 加班**、**数据备份**；另有一条贯穿始终的线 —— **闹钟不再丢**。二十七个测试版的细节读 `v0.13.md`，这里只记门面与交付物。

  **① 统计页（v0.13.14 起，v0.13.17 / 0.13.19 精修）**：日历顶栏的统计入口打开 `StatsScreen`（月 / 年）。算法是 `domain/shift_stats.dart` 的纯函数 `shiftStatsFor` —— 正常工时扣当天请假、`endMinute` 的累计 / 回绕 / 1440 三种形态都认、跨月夜班整段归上班开始那天；「未排班」「空白表」「休息」三件事分开数。图表全部是 `CustomPainter`，不引第三方库：环形图（底轨 + 圆头分段 + 按像素折角的真实缝隙）、出勤构成条、年视图 12 根月度工时柱（顶圆角渐变 + 均值虚线 + 当月高亮）。年视图点年份弹 `showGlassYearPicker`，期间切换汇到 `_setPeriod`，一次操作恰好一记 `select()`。
  **② 请假 / 加班（v0.13.14 / 0.13.17）**：新表 `shift_day_extras`（schema v16，主键 `{day, kind}`，全局按天不挂方案），v0.13.17 加 `leave_kind` / `note` 两列（v17）。类型存**键**（内置五类 + `custom:<名字>`，删类型不动历史）；整天请假由 `planShiftAlarms` 统一抑制那天的班次闹钟。备注是真 `TextField`，按 `viewInsets.bottom` 顶整块面板。**CSV 导出**：任选起止日期与 12 个字段，`domain/stats_export.dart` 生成带 BOM 的逐日 CSV，走系统文档选择器保存。
  **③ 数据备份（v0.13.4，v0.13.5 修重启）**：`.dshbackup` = zip（`VACUUM INTO` 快照 + `prefs.json` + 自选铃声 + manifest）。导入先校验，暂存 `pending_restore/`，由 `main()` 在**任何数据库打开之前**原子替换，再用 `NEW_TASK | CLEAR_TASK` 起新任务（不杀进程 —— Android 14+ 会把「进程已死 + 拉起 Activity」判成后台启动并拦掉）。
  **④ 闹钟不丢（v0.13.15 / 0.13.18 / 0.13.20 / 0.13.21 / 0.13.22）**：重排改「先排后清」（`reconcileNativeAlarms`，差集 `staleNativeIds` 按号段隔离），排盘改一批一次落盘；`AlarmWatchdog` 每 6 小时巡检，且**只往前挪不往后推**（原来每轮重排都把它推后 6 小时，等于从没按时跑过）。取证补了两行：`MainActivity.onCreate` 在 `super.onCreate` **之前**写「系统下一跳 / 清单最早」，以及 `getHistoricalProcessExitReasons` 的退出原因。闹钟页顶部新增「下一次响铃」（看 `overrides`）；「查看日志」改成整页（按天归档保留 7 天、搜索、一键导出诊断包）。
  **⑤ 权限按品牌入手（v0.13.15 / 0.13.22）**：三星「休眠应用」、一加 / OPPO「自启动 / 后台运行」两行，解析不到就不显示。
  **⑥ 节假日自动更新（v0.13.12）**：`holidays.json`（仓库根 + 站点根，`schema 1`）双通道拉取，校验从严、整份通过才认、按年整年替换；「关于」页有手动刷新。
  **⑦ 触觉（v0.13.7 ~ 0.13.10）**：三档语义改走原生通道与设备自己的预定义效果（根因：Flutter 的 `selectionClick` 落到 `CLOCK_TICK`，小米 HAL 回退成 70ms 长震）；跨品牌按 API 等级逐条校准；`catch (Exception)` 全部改 `Throwable`，修掉 HarmonyOS 3.0（API 29）冷启动闪退。
  **⑧ 界面（v0.13.23 / 0.13.24 / 0.13.25 / 0.13.26 / 0.13.27）**：日期弹层点年月标题跳月、`glass_step_button` 统一箭头取色、翻月定高按六周；`glass_sheet_panel` 把手统一 11 个底部弹层；两档 `iconTheme` 补 `color`，全库裸图标不再黑压黑；滑块抓取偏移按**按下点**算（跟手），升程只看「按住」；「版本更新」弹窗首屏三版 + 「展开更早的」胶囊（缓解老机型字形图集问题，**不是根治**，上游 `flutter#190519` 仍 open）。
