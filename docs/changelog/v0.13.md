- **v0.13.1（测试版 · 官网与国内下载镜像）**：GitHub 在国内下载慢、`raw.githubusercontent.com` 经常不通，加一条官网通道（2026-11-10 用户选「A 档 · 零成本」）。
  **① 官网**：`site/` 一页静态站（深空蓝紫 + 磨砂玻璃，沿用 App 的设计语言），入口、截图、更新日志、下载按钮都在这一页。
  **② 部署**：`.github/workflows/site.yml` 在 Release published 时把 `site/` + 六张截图 + 两张 GIF + **本次的 APK** 组装成 `_site/` 推到 Cloudflare Pages（项目 `daoban-shift`），并生成一份指向本站 APK 的 `latest.json`。APK 不进仓库，部署时从 Release 拉一次即弃。清单底稿取 `origin/main:latest.json` —— release 事件是在 `release.ps1` 更新清单**之前**触发的，而 beta 那份的 `stable` 可能停在旧值，只有 main 的权威。
  **③ 更新检查**：`UpdateChecker` 由两通道改三通道（官网清单 → 仓库清单 → GitHub API）。国内以前要先卡满 8 秒超时才回退，现在第一跳就是通的。
  **④ 护栏**：`update_checker_test.dart` 新增「官网地址一致性」用例，扫 `site.yml` 的 `SITE_BASE` 与 `UpdateChecker.siteBase` 比对 —— 改域名漏一处会静默回退，不报错；workflow 里另有 APK > 25 MiB（Pages 单文件上限）直接红的硬闸。
  **数字**：单测 1257 → **1261**；`flutter analyze` 0 issue；版本 `0.13.0+187` → **`0.13.1+188`**。

- **v0.13.0（正式稳定版 · 归纳 0.12.1~0.13.0 十一个测试版）**：这一版把「重复待办」这条线收口，并刷新仓库门面。
  **① 小组件跟随系统深浅色**：三张卡（本周条 / 今日卡 / 整月）在 App 主题为「跟随系统」时，系统切深浅色会当场跟着变，App 进程不在也一样。做法是 API 31+ 文字走 `setColorInt` 日夜双值、背景走同名 `drawable-night`，由桌面重新应用 RemoteViews 时按当时的 `uiMode` 解析；API < 31 没有 `setColorInt`，仍走烤死路径（只翻背景不翻字比不翻更糟）。manifest 那条 `CONFIGURATION_CHANGED` 实测收不到（Android 8+ 隐式广播限制），已删；`MainActivity` 的运行时接收器保留作 App 活着时的兜底。真机（Redmi K90 Pro Max / Android 16 / HyperOS）把 App 强停后切深浅色，三张卡逐张截图验过、logcat 无本 App 日志。
  **② 重复待办行挂发生日**：跨午夜班次的行从「提醒落地日」改回「发生日（班次那天）」；提醒仍按 `alarmDayAnchor` 落在前一天 / 当天 / 次日；副标题写「班次名 · 次日 00:00」。旧版写在显示日的行与旧水位线在升级时**一次性**迁回 / 回退（prefs 键 `recurringRowDayMigratedV1`，覆盖归档行；候选不唯一时不动）。
  **③ 打勾后不再响**：`upcomingFireTimes` 补读 `skipThrough`；取消勾选在等值时撤水位线（「勾错了 → 撤销」提醒会回来）；冷启动改走 `rescheduleAll`（`reschedule` 会取消重复待办号段却不排回来，既有 bug）；「以后不再重复」解绑时把行改到提醒落地日，保住一次性的绝对时刻。
  **④ 排班箭头去掉**：排班管理里每套方案的 `scheme-open-hint` 与编辑排班的值行箭头（`crew-*-chevron` / `my-cycle-start-chevron` / `monthly-day-chevron`）按用户 2026-11-09 的要求去掉；整行仍可点。规则层同步更新为「六处例外」。
  **⑤ 交付物**：README 文案逐条核 + `docs/images/` 的 hero / shot-* 重跑 + 四张 `v0130-*.gif` 重出；`docs/coolapk-post.md` 升 v0.13.0；`PRODUCT_SPEC.md` 抬头与受影响条目；`docs/decisions/widget.md` / `todo.md` / `ui-rules.md`；GitHub 仓库描述与 topics；Release 说明写真实内容（不是自动生成的占位稿）。
  **数字**：单测 1252 → **1257**（新增迁移二跑 / 水位线回退 / 解绑前后两天 / 旧前台点 / auto 资源内容 5 条）；`flutter analyze` 0 issue；版本 `0.12.11+186` → **`0.13.0+187`**。**发布**：`beta → main` 用 `--no-ff`，tag 打在 main，APK 在主 checkout 构建；发完 curl main 的 `latest.json` 核对 `stable = 0.13.0`。
