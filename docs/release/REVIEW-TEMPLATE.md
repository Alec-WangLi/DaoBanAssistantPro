# 正式版独立审查 · vX.Y.Z

> 用法：正式版（`Z = 0`）打 tag 之前，由**独立上下文**（全新一轮对话或只读 subagent）填写本表，
> 存成 `docs/release/vX.Y.Z/review.md`。填写者不参与本版开发，只读代码与提交记录。
>
> 这是**自守**条目：机器不拦，靠 `release` 技能在执行前检查该文件是否存在。
