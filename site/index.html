你每天真正会用到的那几件事

📅 排班日历

内置 20 种倒班方式模板，选中就能起步；周期表自由编辑，也能按月排班。

  • 按天改班：换班、请假只改那一天，不动整套排班
  • 多套方案按日期衔接，「其余时间」可设成无
  • 农历、节气、法定节假日与调休「班」标记
  • 多班组视图，交接班对照一眼看清

⏰ 班次闹钟

跟着排班自动响，未来 60 天自动续排，不用每天设。

  • 一个班次最多挂 10 条闹钟，各自起名字
  • 落点算准「前一天 / 当天 / 次日」，零点班不会错
  • 重启手机自动排回去；锁屏也会全屏响铃
  • 铃声可选内置、系统、自己的音频，或仅震动

✅ 待办日程

交班、开会、领料 —— 记下来，到点提醒。

  • 可按班次重复：上夜班那天自动出现
  • 提醒按当天值班时间落在前一天 / 当天 / 次日
  • 勾完自动收进「已完成」，点回勾就回来
  • 一次性的响过自动消失，天天响点一下「每天」

🧩 桌面小组件

三张固定尺寸的卡，不打开 App 也看得到。

  • 本周条（4×1）、今日卡（4×3）、整月（4×5）
  • 跟随系统深浅色，App 不在运行也切换
  • 标题两侧能翻前后各三个月
  • 点整卡开 App，点某天跳到那天的日历

它不做什么

不需要账号装完就能用，没有注册、没有登录。
不联网也能用排班、闹钟、待办全在本地，没有后端。
不上传数据没有统计、没有埋点、没有广告 SDK。
不锁功能MIT 开源，代码都在 GitHub 上。
