# 倒班助手Pro

自研的排班助手 App —— 从 0 到 1 用 **Flutter 构建**的完全自有代码（`com.daoban.shiftassistantpro`）。

**排班日历 · 班次闹钟 · 待办日程**：为倒班人群打造，一套 App 搞定倒班生活的日常。

> 无账号 · 无广告 · 无后端 · 纯本地离线 · 开源（[MIT](LICENSE)）

---

## ✨ 功能特性

### 📅 排班日历
- **通用轮换引擎**：任意周期长度、任意班次组合、任意班组数量；内置「四班两倒」默认配置（白班 → 上夜班 → 下夜班 → 大休），支持多套排班方案并存与一键切换；锚点日决定整表相位
- **月视图**：每日班次按颜色区分、今日高亮，支持上/下月翻页与一键回今天，也可**年月跳转**（年份滚轮 + 月份网格）
- **农历 + 节假日**：每格显示农历日 / 节气 / 节日；**法定节假日整段标红**（内置 2025/2026 国务院放假安排，每年发布后随版本更新），**调休上班日带「班」小标记**；选中某天可查看干支、生肖等完整农历
- **法定班次（空白表）**：排班方案可设为跟随法定节假日、不做周期轮换，节假日自动休班
- **多班组视图**：除自己班组外，可同时查看其他班组某天班次，方便交接班对照
- **流畅交互**：日期选择块 2D 拖拽跟手、松手自动吸附，点按放大回弹

### ⏰ 联动班次闹钟
- **按班次自动响铃**：每个班次可独立设置响铃时间与开关，跟随排班自动排定未来 60 天、自动续排不过期
- **未来 30 天预览**：闹钟页列出近 30 天将要响的班次闹钟，**每条可单独开关（按天覆盖）**，响过后自动从列表隐藏
- **可靠的原生调度**：系统精确闹钟（`setAlarmClock`）+ 前台服务 + 全屏响铃界面，锁屏也能响
- **自定义闹钟**：一次性 / 每天 / 每周（可多选星期几），独立于排班；新建默认时间即此刻
- **铃声自由选**：内置铃声或系统铃声，支持试听；响铃时可「再睡一会」贪睡 5 分钟
- **测试闹钟**：一键排定 10 秒后的测试闹钟，快速验证整条闹钟链路

### ✅ 待办日程
- 记录交班、开会等事件：标题 + 日期 + 可选时间 + 可选提前提醒
- 完成勾选后**字体变暗 + 删除线**，一眼分清已办未办

### 🚀 更新
- **检查更新**：双通道展示（正式版 / 测试版）各自可下载；冷启动每日自动静默检查一次，仅发现更新的正式版时弹窗提醒
- **应用内直接下载并安装** 新版 APK，无需另开浏览器

### 🎨 外观与体验
- **液态玻璃设计系统**：磨砂面板、玻璃胶囊导航、实时模糊与高光描边，提示条等轻组件也已玻璃化；低端机自动降级为「假玻璃」，保持流畅
- **深空蓝紫渐变**主题，跟随系统 / 浅色 / 深色三档切换；**5 种主色调**可选，深浅色各自适配
- **中 / English 双语**，随时切换

### 🛡 权限与隐私
- 「我的」页内置**权限检测卡**：通知、闹钟和提醒、后台弹出界面、全屏通知、自启动、电池优化逐项检测，未开启一键跳转系统设置（自启动受系统限制，仅提供跳转引导）
- 内置**日志查看**：只记录闹钟链路与错误/崩溃日志，可查看 / 复制 / 清空，排错不再靠猜
- 首次使用有引导说明，每次更新有更新说明
- **数据 100% 留在本地**：无账号体系、无数据上传、无广告 SDK

## 🛠 技术栈

| 项 | 选择 |
|---|---|
| 框架 | Flutter（stable 通道；`app/pubspec.lock` 锁定下限 Flutter ≥ 3.44 / Dart ≥ 3.12；minSdk 26 = Android 8.0+） |
| 状态管理 | Riverpod |
| 本地数据库 | Drift（类型安全 SQLite，响应式查询；schemaVersion 5） |
| 闹钟调度 | flutter_local_notifications + 原生 Kotlin（setAlarmClock / AlarmReceiver / 前台服务） |
| 农历 | lunar_plus（农历 / 节气 / 干支 / 生肖 / 法定节假日） |
| 设计 | 自研液态玻璃设计系统，跟随系统深浅双主题 |

## 📁 项目结构

```
app/                          # Flutter 工程（唯一源码）
├── lib/
│   ├── main.dart             # 入口：初始化闹钟服务、错误日志
│   ├── app.dart              # 根 Widget（跟随系统深浅主题）
│   ├── core/                 # 设计系统：玻璃材质 / 主题 / 通用组件 / 国际化
│   ├── data/                 # Drift 表 + 仓库 + Riverpod providers + 种子数据
│   ├── domain/               # 轮换引擎（纯 Dart，可单测）+ 农历信息
│   ├── features/             # 日历 / 闹钟 / 待办 / 我的 / 排班编辑与管理
│   └── state/                # 应用设置（主题 / 主色调 / 语言）
├── test/                     # 单元测试（轮换引擎等）
└── android/                  # Android 平台层（Kotlin 原生闹钟调度）
scripts/release.ps1           # 一键发版脚本（读版本号 → 校验 → 上传 Releases）
PRODUCT_SPEC.md               # 产品与技术规格（当前现状）
BUILD.md                      # 构建与运行指南
```

## 🔨 构建

前置：Flutter SDK、JDK 17、Android SDK（详见 [`BUILD.md`](BUILD.md)）。

```powershell
cd app
flutter pub get
dart run build_runner build --delete-conflicting-outputs   # 生成 Drift 代码
flutter build apk --release
```

最新版本 **v0.5.0**（正式稳定版）见 [GitHub Releases](https://github.com/Alec-WangLi/DaoBanAssistantPro/releases)。
